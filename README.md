# Резон

Статичный лендинг: `index.html` + `images/`. Без сборки.

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

В `og:image` стоит относительный путь. После публикации замените на полный адрес `https://<логин>.github.io/<репозиторий>/images/portrait.jpg`, иначе превью в соцсетях не подхватится.
