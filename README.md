# Резон

Статичный сайт без сборки:
- `index.html` лендинг на 7 блоков
- `methodology/index.html` веб-версия методологии (адрес `/methodology/`)
- `rezon-methodology.pdf` та же методология в PDF, открывается в 1 клик без форм
- `images/` картинки, `images/og.jpg` превью для Telegram и мессенджеров (1200x630)

OpenGraph-теги указывают на `https://rezonlab.ru/`. Если домен другой, замените его в `index.html` и `methodology/index.html` (поиск `rezonlab.ru`).

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
